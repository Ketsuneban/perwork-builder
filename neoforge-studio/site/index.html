Как работать

Редактор открыт для чтения; сохранение и запуск сборок требуют GitHub.

01 · Чтение

Выбери Java, JSON, TOML или Gradle-файл в левой панели. Просматривать исходники можно без токена.

02 · Доступ

Создай fine-grained GitHub Personal Access Token только для этого репозитория с правами Contents: Read and Write и Actions: Read and Write. Токен хранится только в памяти вкладки.

03 · Разработка

Измени код и нажми «Сохранить». Сайт создаст коммит в GitHub, после чего GitHub Actions запустится автоматически.

04 · Результат

Открой вкладку «Сборки» и выбери завершённый запуск. В GitHub скачай артефакт neoforge-1.21.1-mod, содержащий JAR.

Внимание: исходники, логи и JAR из публичного репозитория могут быть доступны другим людям. Не сохраняй там секреты. Полноценное тестирование мода в Minecraft выполняется отдельно.
