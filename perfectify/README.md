# Perfectify

**Minecraft 1.21.1 • NeoForge 21.1.x • Java 21 • Open Source**

Perfectify improves selected Minecraft Java mechanics with Bedrock-inspired behavior.

Perfectify улучшает отдельные механики Minecraft Java и переносит особенности Bedrock Edition.

Source code is open under the MIT license. Исходный код открыт по лицензии MIT.

### Build / Сборка

```bash
gradle --no-daemon clean build
```

A GitHub Actions workflow builds every push and pull request. Tags `vX.Y.Z` publish GitHub Releases with a downloadable mod JAR and bilingual release notes.

GitHub Actions собирает каждое изменение. Теги `vX.Y.Z` создают GitHub Release с файлом мода и описанием на двух языках.
