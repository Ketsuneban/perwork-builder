# Perfectify — История изменений

## 0.1.0-alpha — 13 ноября 2026

### Архитектура
- Создан самостоятельный проект Perfectify на NeoForge 1.21.1 и Java 21.
- Переименованы mod ID, пакеты Java и пути ресурсов.
- Удалены комментарии из исходных Java-файлов.
- Подготовлены автоматические проверки и публикация версий через GitHub Releases.

### Игровые механики
- Рецепты лодок с деревянной лопатой.
- Руки, предметы во второй руке и редстоун-позы стоек для брони.
- Наполнение котлов зельями, получение зелий и стрел, окрашивание воды и кожаной брони.
- Взвешенный выбор зелий в котлах хижин ведьм.
- Слабые эффекты зелий при контакте с содержимым котлов.
- Динамика снега, ограничение накопления и покрытие растений.
- Изменения ИИ скелетов, криперов и зомби; жест с маком у големов.
- Более мягкая палитра карт, изменение анимации щита, окраска оставшейся шерсти овец.
- Цветовое форматирование чата, подсветка имён и миниатюры скинов.

### Состояние
- Перенесённые механики остаются экспериментальными.
- Требуется игровая проверка Mixins, сетевой синхронизации котлов и точности поведения Bedrock.
- Промежуточные сборки — не публичные релизы.
